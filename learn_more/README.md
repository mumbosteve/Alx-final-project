# Quiz App 📝

A simple and responsive quiz application built with React and Vite. The app allows users to answer multiple-choice questions, track their scores, and get instant feedback. In future versions, the app will fetch quiz questions dynamically from an external API.

## Features
 -Built with React and Vite for fast development
 -Styled with Tailwind CSS 
 -Multiple-choice quiz functionality
 -Real-time score tracking
 -Fully responsive design 
 -Fetch questions from an external API (Open Trivia DB)
